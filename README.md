# Cerberus

An administration panel for Habbo retro hotels, built with Node.js and Express.

# Developers

- habbo-hotel

[![Cerberus demo](https://img.youtube.com/vi/ZK6pWw1TeW0/maxresdefault.jpg)](https://www.youtube.com/watch?v=ZK6pWw1TeW0)

# Local Use

1. Install Node.js and MySQL.
2. Import `cerberus.sql` into a MySQL database named `cerberus`.
3. Update `app/config/database.json` with your database credentials.
4. Install dependencies and start the app:

```sh
npm install
node index.js
```
